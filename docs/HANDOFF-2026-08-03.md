## Cosas a NO tocar (defensivas)

- `MP_WEBHOOK_SECRET` — está bien en Vercel, regenerar solo si es estrictamente necesario
- `RESEND_FROM_EMAIL` — solo cambiar a algo del dominio verificado (formato `algo@vakstoree.com`)
- `SUPABASE_SERVICE_ROLE_KEY` — nunca importar en código del cliente, solo en `src/lib/supabaseAdmin.ts`
- `.env` local — está en `.gitignore`, no commitear nunca
- `webhook_events` table — el `unique(provider, external_id)` constraint es lo que evita doble procesamiento de webhooks

## Si volvés a la sesión y algo no anda

1. **Sitio no carga:** hard refresh (Ctrl+Shift+R). Si sigue, abrir DevTools → Console → ver errores.
2. **Email no llega:** revisar Resend → Logs (filtrar por tu email). Si hay error 422, `RESEND_FROM_EMAIL` no matchea dominio verificado.
3. **Login con Google falla:** revisar Google Cloud Console → Credentials → OAuth Client, verificar que las 3 URLs (redirect + 2 JS origins) sigan. Si falta una, agregala.
4. **Webhook de MP no procesa:** Vercel → Functions → buscar el log del webhook. Si ves "Invalid signature" → `MP_WEBHOOK_SECRET` mal seteado. Si ves "Idempotency check failed" → bug en el insert a `webhook_events`.
